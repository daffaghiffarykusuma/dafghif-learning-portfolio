# Issue tracker

This project uses [GitHub Issues](https://github.com/daffaghiffarykusuma/dafghif-learning-portfolio/issues) in `daffaghiffarykusuma/dafghif-learning-portfolio`.

- Implementation-ready specifications and tickets use the existing `ready-for-agent` label.
- Read the full issue and comments before implementation. Ticket bodies declare their blocking dependencies; priority alone is not a dependency.
- Implement a specification on an integration branch and reference its tickets in the pull request. Use closing references for completed work so GitHub closes the issues when the pull request merges into the default branch.
- Do not close issues merely because a draft pull request exists. Keep incomplete verification explicit in the pull request.

This records the tracker and label already used for specification #23 and tickets #24 through #28.
