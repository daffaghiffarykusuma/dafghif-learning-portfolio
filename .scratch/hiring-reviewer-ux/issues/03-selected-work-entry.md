# Lead Hiring Reviewers from the homepage to selected work

## Parent

[Specification #23: Hiring-first evidence review and reliable portfolio browsing](https://github.com/daffaghiffarykusuma/dafghif-learning-portfolio/issues/23)

## What to build

A Hiring Reviewer can start an initial shortlist review from the homepage's primary Explore selected work action, or download the CV beside it. Learning design leads the positioning, with program management as supporting breadth. The current three selected Case Studies remain the curated entry, and the complete catalogue remains easy to reach.

This is a complete homepage entry-path change using the existing navigation and selected-work section. It does not require new summaries to be published first.

## Acceptance criteria

- [ ] Explore selected work is the primary homepage action and reaches the existing selected-work section. Download CV remains beside it and retains the published CV destination.
- [ ] Homepage positioning emphasizes learning design and instructional design, with program management supporting that focus, without adding unsupported experience or outcome claims.
- [ ] Administrative Communication, Learning Organization Strategy, and Entrepreneurship remain the selected cases, with working native Case Study links. No competing curated list is introduced.
- [ ] The complete catalogue remains accessible through navigation and a clear action after selected work.
- [ ] The route is usable by keyboard and at desktop 1280 by 800 and phone 390 by 844 CSS pixels. The destination and next action are understandable without relying on animation.
- [ ] Preserve the dark editorial visual language, existing mobile navigation behavior, reduced-motion support, and below-fold mobile portrait loading policy.
- [ ] Update relevant initialized-page navigation coverage to reflect the new primary destination and verify the CV, case, and catalogue routes. Avoid new tests that only mirror incidental styling or copy.
- [ ] Inspect the complete home-to-selected-case path against the production preview at both viewport sizes. No Artifact or CV content changes are required.
- [ ] Existing type checks, automated tests, site validation, production build, and performance guards pass. Report visual inspection separately from automated checks.

## Blocked by

None (can start immediately). The selected cases already exist; improved Case Study summaries can land independently.
